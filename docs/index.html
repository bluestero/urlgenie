Independent checks, each returning a plain true/false — validate_url, validate_email, validate_phone, validate_social, and validate_social_platform / validate_social_profile for a specific platform.

URL validate_url(url) — syntactically valid, resolvable host, real public suffix.
Email validate_email(email, url=) — syntax check, optionally scoped to a site's domain.
Phone validate_phone(phone) — plausible digit count, rejects obvious ids/timestamps.
Social validate_social(url) — a valid URL is not necessarily a valid social profile.
Social platform validate_social_platform(url, platform) — is this a URL on that platform at all?
Social profile validate_social_profile(url, platform) — does it resolve to an actual profile there? Same input as above shows the split: recognized as Facebook, but not a profile.

generalize(url) — cleans and standardizes a single URL. Automatically recognizes and canonicalizes social profile links (Facebook, LinkedIn, Twitter/X, Instagram, YouTube) as well as ordinary websites.

Advanced flags (keep_path, keep_userinfo, force_https)

⚠ If Recognize social profiles is on and the URL matches one, its canonical profile URL is returned as-is — every other flag above is ignored for that result.

generalize_many(urls) — cleans a batch of URLs at once, one per line or comma-separated. Every result stays aligned with its input, even the invalid ones. Rows that generalize to the same result — however differently they were spelled — are flagged as duplicates.
